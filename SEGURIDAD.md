# Publicación segura

No publicar bases de datos SQLite de clientes, respaldos, usuarios, contraseñas, tokens, credenciales de hosting ni archivos de configuración privados.

Antes de publicar código PHP de producción, auditar credenciales embebidas, rutas, autenticación, consultas SQL y dependencias. Preparar una copia independiente con datos ficticios.

Las capturas deben tomarse de una demo y ocultar datos personales.
